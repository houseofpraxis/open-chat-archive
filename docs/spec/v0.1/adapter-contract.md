# Adapter and model-disclosure contract

Adapters implement the typed `Adapter` protocol: versioned namespace, profile-only fingerprint recognition, normalization/conformation, coverage ledger, code-only diagnostics, and `BatchResult`. Unknown or multiple matching fingerprints fail closed. The scaffold CLI creates explicit owned Python files plus positive/negative synthetic fixtures and tests.

Built-in adapters use an explicit operator-selected format at import time (`claude-ai`, `claude-code`, `open-webui`, `codex`, `grok-build`); recognition is a conservative shape-only aid, not authorization to parse an unselected format. They accept regular non-symlink local files only, retain exact input bytes as a source artifact, and emit immutable `records.ndjson` and `manifest.json` batches. Raw conformation validates the source structure independently and exposes only fixed failure codes. Source/batch observations are physical evidence and do not change semantic entity or revision identities. The initial built-ins bind mapped semantic fields to the exact source artifact. JSON sources use a JSON Pointer plus the whole-artifact byte range; JSONL sources use `jsonl_line` plus that byte range. A JSON Pointer is not claimed for a JSONL record. Mapped coverage-ledger rows name canonical destinations for projected profile paths; remaining profile paths stay `preserved` in the source artifact.

An adapter may use a narrowly scoped source parser when a documented source format has finite decimal tokens that canonical JSON intentionally cannot represent. Such a parser must retain the exact token without binary floating-point conversion, must keep the resulting value non-canonical, and must never place it in a record body or extension. Generic strict loaders and shape profiling retain their normal float rejection except for disclosing that wrapper as the JSON type `number`.

The model-visible dossier contains only `shape-only-v1` opaque alias topology, JSON types, bounded cardinality buckets, structural coordinates, synthetic fixtures, and optionally locally approved semantic alias labels. Those labels are never raw source keys. Raw bytes, raw keys, the protected key map, source execution, conformed output, and diagnostics audit remain local/model-forbidden.

Every encountered profile path appears exactly once in the coverage ledger. `mapped` requires destinations, `preserved` requires a target/reference, and `ignored` requires a reason. The local verifier imports a scaffold, checks positive/negative recognition, runs synthetic conformation twice, validates both batches, reconciles coverage, checks semantic repeatability, and audits stdout/stderr/model-visible artifacts for supplied canaries.

This project does not implement an OS sandbox, process resource isolation, or network denial for generated adapters. Running untrusted/generated code in a no-network sandbox with resource limits is an operator requirement. Diagnostics expose fixed codes and approved structural coordinates only.
