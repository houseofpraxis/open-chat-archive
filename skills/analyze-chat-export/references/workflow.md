# Workflow

1. Preserve exact bytes and record digest/size before parsing.
2. Reject symlinks/devices, BOM, invalid UTF-8, duplicates, floats/non-finite numbers, bad limits, and excess input/output.
3. Produce opaque alias topology, JSON types, bounded cardinality buckets, and structural coordinates only.
4. Scaffold owned files and positive/negative synthetic fixtures from the profile.
5. Optionally add locally reviewed semantic alias labels that are not raw source keys.
6. Locally implement and execute conformation, fail closed on unknown/ambiguous fingerprints, verify twice, reconcile coverage, validate the archive, and audit canaries.

ZIP/Markdown profiling and OS sandbox/network enforcement are not implemented.
