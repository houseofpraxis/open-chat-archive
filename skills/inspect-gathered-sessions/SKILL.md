# Inspect gathered sessions

Collection is not import. `oca-gather` snapshots exact local JSONL bytes. This skill drives the later offline Python/Go inspection path. It does not invent account ownership, repair logs, or treat a gather receipt as a completed canonical import.

Keep every sensitive artifact local and model-forbidden: gather stores, receipts, objects, operator plans, ledgers, canonical archives, HTML sites, Markdown vaults, attestation files, and `--details` reports. Share only aggregate JSON, fixed error codes, and counts. See [workflow](references/workflow.md).
